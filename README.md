# Fantine Mpacko Priso

Graduate student in Computer Science at UC Berkeley and ENS Paris-Saclay.

Interested in machine learning, computational health, neuroscience, and human-centered AI.

## Selected work

**Face Reconstruction**  
Participant-specific facial prototype reconstruction from pairwise judgments using Bradley–Terry models, MediaPipe landmarks, similarity alignment, Delaunay triangulation, and piecewise-affine morphing.

**Modular Manifold Muon**  
Riemannian L-BFGS inner solver for the Muon optimizer, with experiments on MLPs, CNNs, and Vision Transformers.

**Minority Estimation**  
Behavioral experiment studying minority proportion estimation with controlled social and non-social visual stimuli, including stimulus generation, experimental deployment, and analysis tooling.

**UFO.recordz**  
Full-stack website and data infrastructure for an independent music label, built with React, TypeScript, Tailwind, Supabase, and Vercel.
